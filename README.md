# 청약·정비 레이더

서울·경기 청약 일정(청약홈 공고)과 재건축·재개발 파이프라인(공고 전 단계)을 매일 자동으로 모아
한 페이지에서 보는 도구입니다. GitHub Actions가 매일 06:10(KST)에 수집하고, GitHub Pages로 웹에 띄웁니다.

```
청약홈 API ─┐
서울시 정비사업 엑셀(분기) ─┼─> tracker/run.py ─> docs/data/data.json ─> docs/index.html (GitHub Pages)
data/watchlist.csv(직접 관리) ─┘          └─> data/state/ (스냅샷 비교 → 새 공고·일정 변경·단계 변경 기록)
```

| 화면 | 내용 |
|---|---|
| 추천 순위 | 지금 넣을 수 있는 공고를 가치 점수(시세 여유율 + 최근 상승률) 순으로. 신뢰도 표시 |
| 청약 일정 | APT·무순위·임의공급 공고. 다음 일정 기준 D-day, 특공/1·2순위/발표/계약 타임라인, 평형별 분양가. 정렬(분양가·3.3㎡당·시세 여유·가치 점수·내 자격)과 **평형별 가격표**(열 제목을 눌러 정렬) |
| 정비사업 | 서울 정비구역 약 500곳의 단계(구역지정→…→관리처분→착공), 세대수, 추진 이력 + 관심목록 |
| 변경 이력 | 새 공고, 정정(일정 변경), 단계 변경, 신규 구역 |
| 초보 가이드 | 청약 순서, 1순위 조건, 예치금, 가점/추첨 비율, 가점표, 특공, 용어, 공식 사이트·앱 목록. 숫자마다 공식 근거(법 조문·정부 발표) |
| 용어집 | 부동산·청약 용어 51개를 7개 분류로. 쉬운 설명 → 자세히 → 법령·정부 근거 링크. 검색 가능 (`tracker/terms.py`) |

공고 카드에는 **평형별 분양가**(전용㎡ · 평형 · 가격대 · 3.3㎡당 · 세대수)가 바로 보이고, 펼치면 **조건 쉽게 보기**(규제지역·1순위·예치금·비율·당첨 후 제한·필요 현금),
**시세 분석**(국토부 실거래가 기반), **공식 수치**(청약홈 경쟁률 등), **공식 발표**(정부·지자체·LH·SH·GH)가 나옵니다.

## 근거는 공식 발표만

- 링크와 수치의 근거는 **정부·지자체·공공기관** 자료만 씁니다: 국가법령정보센터(주택공급에 관한 규칙·주택법), 국토교통부·정책브리핑(korea.kr),
  금융위원회, 서울시·경기도·구청(*.go.kr), 청약홈, 한국부동산원, LH·SH·GH, 공공데이터포털.
- 언론 기사·블로그·민간 앱·AI 추정치는 근거로 쓰지 않고 링크도 달지 않습니다. `tracker/sources.py` 가 화이트리스트이고,
  `run.py` 가 data.json을 쓰기 직전에 비공식 링크를 한 번 더 걸러 냅니다(`sources.sanitize`).
- 공식 발표가 없는 '분양 예정 시기'(업계 계획)는 **'공식 공고 전 · 보도 기준'** 으로 따로 표시하고 기본으로 숨깁니다.
- 공식 원문으로 금액을 아직 확인하지 못한 자격 기준(청년 특공 소득·자산, 공공 총자산 등)은 '금액 미확인'으로 표시합니다.

## 내 자격 · 곧 나올 분양 · 지도 · 최신 정보

**내 자격 탭**
- 생년월일, 혼인 상태, 세대주, 주택·오피스텔, 통장, 소득, 자산, 가족을 넣으면 청약 종류별로 넣을 수 있는지를 바로 계산합니다(국민주택 7종, 민영 6종, 무순위·임의공급).
- 결과는 ✓ 가능 / 확인 필요 / 나중에 가능 / 불가 네 가지로 나오고, 이유를 함께 보여 줍니다.
- '혼인신고 후' 결과와 가점(지금 → 혼인 후)도 나란히 보여 줍니다.
- 모든 공고 카드에 '내 자격' 표시가 붙습니다. 추천 순위·청약 일정에서 **✓ 내 자격 되는 것**만 걸러 볼 수 있습니다.

**기본값과 저장 위치**
- 기본값은 PC의 `profile.local.json` 입니다(`profile.example.json` 참고).
- 이 파일은 `.gitignore` 로 GitHub에 올라가지 않습니다.
- 같은 PC·같은 와이파이에서만 읽고 저장되며, 터널(외부)로 들어온 요청에는 보이지 않습니다.
- 휴대폰에서 고친 값은 '이 기기에 저장'(브라우저) 또는 'PC에도 저장'으로 남깁니다.

**계산 규칙**
- 판정 기준값은 `tracker/guide.py` 의 `ELIG_PARAMS` 에 있습니다(소득 기준표, 자산 한도, 예치금, 가점/추첨 비율). 해마다 바뀌면 여기만 고치면 됩니다.
- 계산은 `docs/app/elig.js` 에서 브라우저가 직접 합니다. 개인 정보는 서버로 가지 않습니다.
- 오피스텔은 청약 무주택 판정에서 주택 수에 넣지 않습니다(준주택). 다만 공공분양 자산 기준에는 부동산으로 들어갑니다.

**곧 나올 분양 탭** — 한 화면에 네 가지를 모았습니다.
1. 공고 났고 접수 전인 단지
2. 공고 전 분양 예정 단지 (`data/watchlist.csv` 의 stage=분양예정, 월별). 청약홈 공고가 뜨면 이름으로 짝지어 '공고 나옴'으로 바뀝니다.
3. 분양 후보: 서울 정비구역 중 관리처분 또는 최근 2년 안에 착공한 곳
4. 공식 발표: 정책브리핑·국토부·서울시·경기도·LH·SH·GH의 분양·입주자모집 관련 글 (갱신 때마다)

**지도 탭**
- 접수 예정·진행(초록), 무순위·임의(노랑), 분양 예정(보라), 정비 막바지(빨강), 서울 정비구역 전체(회색, 기본 꺼짐)를 지도에 표시합니다.
- 카드의 '지도' 링크를 누르면 그 위치로 이동합니다.
- 좌표는 카카오(`KAKAO_REST_KEY`, 추천) → 브이월드(`VWORLD_KEY`) → OpenStreetMap 순으로 찾고 `data/state/geocode.json` 에 저장합니다.
- 키가 없으면 OpenStreetMap으로 ① 동 중심(같은 동의 여러 곳은 겹치지 않게 살짝 벌림) ② 이름이 정확히 같은 아파트 단지(동 중심 2km 안)를 찾습니다.
  무료 검색은 번지까지는 못 찾으므로 대부분 '동 단위'입니다. 실행당 300건씩 찾고, 남은 곳은 다음 갱신 때 이어서 찾습니다.
- 표시: 진한 점 = 단지·번지 위치, 점선 = 동 단위, 옅은 점선 = 구 중심(대략). 지도 아래에 각각 몇 곳인지 나옵니다.
- 네이버 지도를 쓰려면 네이버 클라우드 플랫폼 콘솔 → Maps → Application 등록(Geocoding 선택) 후 Client ID/Secret을 `NAVER_MAP_ID`, `NAVER_MAP_SECRET` 에 넣습니다(GitHub는 같은 이름의 Secret). 키가 틀리면 자동으로 무료 지도로 돌아갑니다.
- **카카오 키(무료)를 넣으면 번지 단위로 거의 전부 정확해집니다.** [Kakao Developers](https://developers.kakao.com/) → 내 애플리케이션 → 앱 만들기 → 앱 키의 'REST API 키'를 `.env` 의 `KAKAO_REST_KEY=` 에 붙여 넣고 서버를 다시 켜세요.

**최신 정보 가져오기** (PC에서 `serve.py` 로 띄웠을 때)
- 페이지를 열거나 앱으로 돌아올 때, 데이터가 1시간 넘게 지났으면 자동으로 새로 받습니다.
- 위쪽 **↻ 최신 정보** 버튼을 누르면 바로 받습니다. 끝나면 새 공고·변경 건수를 알려 줍니다.
- 서버는 3시간마다(`--every`), 매일 06:10(`--daily`)에도 갱신합니다.
- GitHub Pages(정적)에서는 버튼이 숨겨지고 Actions 일정대로만 갱신됩니다.

## 포트폴리오 정리 보드 (`/portfolio/`)

Asset 프로젝트의 '해외주식 포트폴리오 6개월 정리 계획'을 웹 보드로 옮긴 페이지입니다. 같은 `serve.py` 로 함께 뜹니다.
- 주소: `http://PC주소:8000/portfolio/`. 청약 레이더 위쪽의 **포트폴리오** 버튼으로도 갈 수 있습니다.
- 휴대폰 홈 화면에 따로 추가해 두면 편합니다.

**탭 구성**
- **오늘 할 일:** 이번 달이 정리 시기인 종목을 보여 줍니다. 지난 달이 시기였는데 아직 남은 종목이 먼저 나옵니다. 종목마다 아래 표시가 붙습니다.
  - 반등일(+3% 이상) → 분할 매도 고려
  - 급락일 → 투매 금지
  - 목표가 도달, 본전 이상
  - 계획 가격 대비 ±35% 이상 → 액면분할·병합 여부 확인
- **종목:** 현재가, 오늘 등락, 3개월 추이와 평단선, 평단 대비 수익률, 본전까지 필요한 상승률, 계획일(11/2) 대비 변화를 보여 줍니다.
  - 보유 수량·평단·목표가는 입력하면 바로 저장됩니다.
  - '매도 기록하기'로 남기면 보유 수량이 자동으로 줄어듭니다.
- **일정:** 종목별 정리 시기 막대(11월~5월)와 주요 일정 D-day를 보여 줍니다.
- **매도 기록·세금:** 올해 실현 손익과 양도세 추정(250만원 공제, 22%)을 계산합니다.
  - 12/31 전에 손실을 실현해 통산할 여력도 보여 줍니다.
  - 환율은 매도일 기준 근사치라, 실제 신고는 증권사 계산서를 기준으로 하세요.
- **원칙:** 계획 문서의 목표·원칙·체크리스트입니다.

**개인 정보 보호**
- 보유 정보는 `portfolio.local.json` 에, 시세 캐시는 `data/private/` 에 있습니다. 둘 다 `.gitignore` 로 GitHub에 올라가지 않습니다.
- `/api/portfolio` 는 같은 PC·같은 와이파이에서만 응답합니다. GitHub Pages나 터널(외부)로 열면 "PC에서만 열립니다" 안내만 보입니다.

**시세와 종목 관리**
- 시세는 Yahoo Finance 차트 데이터입니다(키 불필요, 지연 가능). 페이지를 보고 있는 동안 5분마다, 또는 ↻ 버튼으로 받습니다.
- 종목을 더하거나 빼려면 `portfolio.local.json` 의 `holdings` 를 고치세요(`portfolio.example.json` 참고).

## 0. 내 PC에서 바로 띄우기 (GitHub 없이)

**Windows**: 폴더의 `run_server.bat` 더블클릭 → 처음 한 번 가상환경을 만들고 실행합니다.
**macOS/Linux**: `./run_server.sh`  (또는 `pip install -r requirements.txt qrcode` 후 `python serve.py`)

1. `.env.example` 을 `.env` 로 복사해 `DATA_GO_KR_KEY=발급받은키` 를 적습니다(지도용 `KAKAO_REST_KEY` 는 선택). 키 없이 보려면 `run_server.bat --demo`.
   내 정보 기본값은 `profile.local.json` 에서 고칩니다(웹 '내 자격' 탭에서 고쳐도 됨).
2. 실행하면 창에 주소와 QR이 나옵니다.
   - 이 PC: `http://localhost:8000`
   - 휴대폰(같은 와이파이): `http://192.168.x.x:8000` — 카메라로 QR을 찍으면 바로 열립니다.
3. 창을 켜 둔 동안 매일 06:10에 자동 갱신됩니다. 창을 닫으면 서비스도 멈춥니다.

**휴대폰이 접속 안 될 때**
- Windows 처음 실행 때 뜨는 "Windows 보안 경고(방화벽)"에서 **개인 네트워크 허용**을 누르세요. 놓쳤다면
  관리자 PowerShell에서 `New-NetFirewallRule -DisplayName "청약레이더" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private`
- 휴대폰이 **같은 와이파이**인지 확인 (LTE/5G면 안 됨). 회사·카페 와이파이는 기기 간 접속을 막는 경우가 많습니다.
- PC 네트워크가 "공용"으로 잡혀 있으면 설정 → 네트워크 → 해당 와이파이 → **개인**으로 바꾸세요.
- 다른 프로그램이 8000번을 쓰면 `run_server.bat --port 8080`.

**집 밖(LTE·다른 와이파이)에서 보기** — 기본 주소(192.168.x.x)는 **같은 와이파이에서만** 열립니다. 밖에서 보려면 두 방법 중 하나를 고르세요.

| | Tailscale (추천) | `--tunnel` (cloudflared) |
|---|---|---|
| 누가 볼 수 있나 | 내 계정에 로그인한 내 기기만 | 주소를 아는 누구나 |
| 주소 | 고정 (`http://100.x.x.x:8000`) | 실행할 때마다 바뀜 |
| 내 정보·포트폴리오 | **열림** (내 기기로 인정) | 숨김 (보안상 막음) |
| 준비 | PC·휴대폰에 Tailscale 앱 설치 후 같은 계정 로그인 | PC에 cloudflared 설치 |

**Tailscale**: [tailscale.com/download](https://tailscale.com/download) 에서 PC(Windows)와 휴대폰에 설치하고 같은 계정(구글 등)으로 로그인 →
`python serve.py` 를 다시 켜면 창에 `Tailscale: http://100.x.x.x:8000` 주소가 나옵니다. 휴대폰에서 Tailscale을 켠 상태로 그 주소를 열면 됩니다.

**터널** — `python serve.py --tunnel`
- [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 설치 필요
  (Windows: `winget install --id Cloudflare.cloudflared`). 실행하면 `https://xxxx.trycloudflare.com` 주소와 QR이 나옵니다.
- 이 주소는 **실행할 때마다 바뀌고**, 주소를 아는 사람은 누구나 볼 수 있습니다(인증키는 노출되지 않음).
  고정 주소가 필요하면 아래 GitHub Pages 방식이 더 편합니다(PC를 꺼 둬도 매일 갱신).

**휴대폰 홈 화면에 앱처럼 추가**
- iPhone(Safari): 공유 → 홈 화면에 추가 · Android(Chrome): ⋮ → 홈 화면에 추가
- 아이콘과 이름 '청약레이더'로 전체 화면 앱처럼 열립니다. 별표(관심)와 필터는 기기마다 따로 저장됩니다.

**PC를 켤 때 자동 실행 (Windows)**: `Win+R` → `shell:startup` → `run_server.bat` 의 바로가기를 넣어 두세요.

## 1. GitHub Pages로 띄우기 (PC를 꺼 둬도 됨, 15분)

1. **인증키 발급** — [공공데이터포털](https://www.data.go.kr)에 가입하고 아래 API를 **각각 활용신청**합니다(개발계정 자동승인, 키는 하나로 공통).
   마이페이지 → 일반 인증키 **Decoding** 값을 복사. 승인 후 동작까지 1~2시간 걸릴 수 있습니다.

   | API | 쓰는 곳 | 필수 |
   |---|---|---|

### 시세 비교값과 지역 동향을 직접 보태기

시세 분석은 국토부 실거래가 API(공식)로 자동 계산합니다. 그 밖에 보태고 싶은 값은 아래 두 파일에 적되, **url이 공식 사이트(국토부 실거래가 공개시스템 rt.molit.go.kr, 한국부동산원 reb.or.kr, 청약홈 등)인 줄만** 반영됩니다. 기사·블로그·민간 시세 앱 값은 무시됩니다.

- `data/comps.csv` — `target`(공고명 일부), `band`(59/84 등), `comp_name`, `build_year`, `price_manwon`, `date`,
  `kind`(실거래·KB시세·AI추정·시세범위·분양가), `source`, `url`, `note`. `분양가`는 '인근 분양가 비교'로, 나머지는 '기대 시세'로 쓰입니다.
- `data/region_trends.csv` — `region`(예: `수원시 권선구`, `경기`), `metric`(주간·월간·3개월·연초 대비), `change_pct`, `source`, `url`, `date`.
  같은 지역·같은 지표가 여러 출처면 중앙값과 일치 여부를 냅니다. 구 자료가 없으면 시 → 시·도 순으로 찾아 씁니다.

### 투자 점수 계산 방법

```
A          = 대표 주택형 전용면적,  P = 대표 주택형 분양가(주택형별 최고가의 중앙값, 보수적)
비교 거래  = 국토부 실거래가 중 최근 6개월(부족하면 12개월), |전용 − A| ≤ 8㎡, 준공 10년 이내, 해제·직거래 제외
단지 값    v_c = median(거래가 ÷ 전용면적) × A
기대 시세  E = 공고에서 실제 거리 1→2→3km 안 단지가 3곳 이상 되는 첫 반경의 median(v_c)   ← 근거 없으면 계산 안 함
시세 여유율 = (E − P) ÷ P × 100      (토지임대부는 임대료 ÷ 4%를 분양가에 더해 비교)
보유 기간  = max(실거주의무, 2년)     ← 입주(잔금) 후 2년 안 매도는 양도세 60~70%(소득세법 제104조)
묶이는 기간 = max(전매제한, 입주까지 남은 기간 + 보유 기간)
투자 점수  = 시세 여유율 ÷ 묶이는 기간   (시세 여유율 ≤ 0 이면 나누지 않음)
신뢰도     = 반경 1km·단지 4곳·거래 15건 이상 '높음', 2km 이내 '보통', 그 밖 '낮음'
```
점수는 비교를 돕는 지표일 뿐 투자 권유가 아닙니다.

### 기대 시세는 어떻게 내나 (실측 근거)

1. 국토교통부 아파트 매매 실거래가(공식)에서 공고 주택형과 같은 면적대(전용 ±8㎡), 최근 6개월(부족하면 12개월), 10년 이내 준공 거래만 고릅니다. 해제된 거래와 직거래는 뺍니다.
2. 단지별로 전용㎡당 중앙값을 내고, 공고 주택형 면적을 곱해 환산합니다.
3. 공고 위치와 각 단지의 **실제 좌표(번지·단지 단위)** 로 거리를 재서, 반경 1km → 2km → 3km 순으로 단지 3곳 이상이 잡히는 첫 반경의 '단지 값들의 중앙값'을 기대 시세로 씁니다.
4. 비교 단지 표(단지명·준공·거리·거래 건수·환산값·최근 거래일)를 화면에 그대로 보여 줍니다.
5. 이 조건을 못 채우면(위치를 번지까지 못 찾았거나 가까운 비교 단지가 모자라면) **추천 순위에서 빼고** '근거 부족'과 이유를 표시합니다.
   거리 계산에는 카카오(또는 네이버·브이월드) 키가 필요합니다.

### data/notice_rules.csv — 공고문에서 확인한 전매·실거주·재당첨 값

앱은 전매제한·실거주의무·재당첨 제한을 주택법·시행령 기준으로 **추정**해 '법령 기준 추정'으로 표시합니다(실거주의무는 3~5년처럼 범위).
입주자모집공고문에서 확인한 값을 `house_manage_no`(청약홈 주택관리번호) 기준으로 한 줄 넣으면 '공고문 확인'으로 바뀌고, 투자 점수의 묶이는 기간도 그 값으로 계산합니다.
`source_url` 은 청약홈·LH·SH·GH 등 공식 주소여야 반영됩니다.

## 줍줍 탭과 알림

**줍줍 탭**: 청약홈 공식 데이터(무순위·잔여세대·임의공급)를 접수 예정·진행 / 발표·계약 남음 / 최근 종료로 나눠 보여 줍니다.
카드마다 공고 원문(청약홈) 링크, 평형별 가격, 내 자격, 신청 방법과 주의할 점(2025.6.10 개정 주택공급규칙 근거)이 붙습니다.

**알림** (`tracker/notify.py`, `config.toml` 의 `[notify]`) — 새 줍줍 공고가 올라왔을 때, 그리고 접수 하루 전에 보냅니다. 기본은 GitHub Actions 에서만 보냅니다.

1. **GitHub 앱 (설정 불필요)**: 갱신 작업이 저장소에 '줍줍' 이슈를 만들고 저장소 주인을 @멘션합니다.
   휴대폰에 GitHub 앱을 깔고 로그인한 뒤, 앱 설정에서 푸시 알림을 허용하면 됩니다. 메일로도 옵니다.
2. **텔레그램 (가장 빠름)**:
   1. 텔레그램에서 `@BotFather` 를 찾아 `/newbot` → 봇 이름과 아이디(…bot) 입력 → **토큰**을 받습니다.
   2. 방금 만든 봇과 대화를 열고 아무 말이나 보냅니다.
   3. 브라우저로 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어 `"chat":{"id":숫자` 의 숫자를 복사합니다(**chat id**).
   4. GitHub 저장소 Settings → Secrets → Actions 에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 로 넣습니다.

처음 실행 때는 이미 올라와 있는 공고를 '본 것'으로만 기록하고 보내지 않습니다(`data/state/notified.json`).

## 한국부동산원 R-ONE 통계 (선택, 아직 연결 전)

공공데이터포털의 '한국부동산원_부동산통계 조회 서비스'는 제공형태가 LINK라 거기서는 활용신청이 안 됩니다.
R-ONE(https://www.reb.or.kr/r-one/portal/openapi/openApiDevPage.do)에 회원가입·로그인 → Open API → 인증키 발급 후
GitHub Secret `REB_KEY` 로 넣으면 다음 업데이트에서 주간 아파트 가격지수를 연결합니다.

## 보는 범위 (핵심지역 · 주변 시세 하한)

화면 맨 위 막대에서 언제든 바꿀 수 있고, 기본값은 `config.toml` 의 `[focus]` 입니다. 줍줍 알림도 같은 기준을 따릅니다.
- **🎯 핵심지역만** (기본 켜짐): 정부가 지정한 규제지역(투기과열지구·조정대상지역)만 봅니다.
  판단은 청약홈 공고의 규제 표기(공식)를 먼저 쓰고, 표기가 없으면 같은 시·군·구 최근 공고 표기 → 10·15 대책 목록 순서로 정합니다.
  그래서 대책 이후 추가 지정된 곳도 자동으로 따라갑니다. `include` / `exclude` 로 시·군·구를 더하거나 뺄 수 있습니다.
- **주변 시세 10억↑** (기본): 공고 위치 주변 실거래(거리 기반)로 낸 기대 시세가 10억 미만이면 숨깁니다.
  시세 근거가 없는 공고는 숨기지 않고 '시세 근거 없음' 꼬리표를 붙입니다(좋은 기회를 놓치지 않도록).
